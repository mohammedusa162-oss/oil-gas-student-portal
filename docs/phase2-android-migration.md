# المرحلة 2 — تقرير فحص «بوابة الطالب» وتحويله إلى Android

تاريخ الفحص: 2026-10-30 · المصدر: `mohammedusa162-oss/oil-gas-student-portal` (فرع `main`، آخر إرسال 2026-10-26)

---

## 1) ما هو المشروع

| البند | النتيجة |
|---|---|
| الاسم | بوابة الطالب — هندسة النفط والغاز، جامعة الزاوية |
| النوع | واجهة (SPA) لطلاب البترول/الجيولوجيا: تتبع 161 وحدة دراسية عبر 58 مادة، 10 فصول + مواد اختيارية، مع تقرير طباعة/PDF |
| التقنية | React 19 + Vite 7 + Tailwind 4 + Radix/shadcn + wouter · TypeScript 5.6 · **pnpm** |
| البنية | `client/` (الواجهة) · `server/index.ts` (مقدّم ملفات ثابتة فقط — **لا API**) · `shared/const.ts` |
| التخزين | `localStorage` فقط (اسم الطالب + المواد المكتملة + اختيار التقرير) |
| النشر | GitHub Pages عبر `.github/workflows/deploy-pages.yml` مع `BASE_PATH=/oil-gas-student-portal/` |
| الاختبارات | لا توجد ملفات اختبار؛ `pnpm check` = `tsc --noEmit` |

## 2) ما تحققت منه

- **لا توجد واجهات خادم** — الخادم يقدّم ملفات ثابتة فقط ويُرجع `index.html` لكل المسارات.
- **لا تتصل الواجهة بأي API**؛ الطابعات الخارجية الثلاث (منظومة الطالب، مرجع خريطة المواد، صفحة الكلية على Facebook) تفتح في المتصفح الخارجي.
- `components/Map.tsx` **غير مستخدم** (استُخدمت أيقونة `Map` من lucide كزينة فقط) → لا Google Maps ولا مفتاح خرائط.
- **ملاحظة أمنية/خصوصية أصلحتها:** كان التطبيق يجلب خط «عارف رقعة» من `fonts.googleapis.com` عند التصدير. هذا نداء شبكة يجعل الطباعة تخسر الخط دون إنترنت ويُعرّض IP لطرف ثالث. **ثبّتُ الخط داخل التطبيق** (`client/public/fonts/aref-ruqaa-{400,700}.ttf`، رخصة SIL OFL) وأُسقط النداء الخارجي بالكامل، وأعدت البناء واختبرت أن الخط يُقدَّم من الحزمة.
- سكربت تتبّع Manus لا يُحقن في بناء الإنتاج (`NODE_ENV=production`) — تحققت من ذلك في `dist/public/index.html`.

## 3) قرار التحويل: Capacitor

نفس المنطق الذي طبّقته على مشروع «متتبع البحث»: الواجهة كاملة وأصلية، والتخزين محلي، ولا خادم — فالتغليف المحلي يعطي تطبيقاً **يعمل بالكامل دون إنترنت** بلا إعادة كتابة.

- `compileSdk/targetSdk = 36` (Android 16) افتراضياً في Capacitor 8 → يحقق شرط Google Play منذ 2026-08-31.
- `minSdk = 24` (Android 7.0).
- `applicationId = com.mohammedusa162.oilgasportal` (ثابت — لا يتغيّر بعد أول نشر).

## 4) التعديلات التي أجريتها على المستودع

| الملف | التعديل | السبب |
|---|---|---|
| `capacitor.config.json` | جديد | هوية التطبيق والـ webDir |
| `android/` | جديد | مشروع Android (Capacitor 8) |
| `client/src/pages/Home.tsx` | تحميل خط Ruqaa محلياً بدل Google Fonts | طباعة تعمل دون إنترنت + لا اتصال بطرف ثالث |
| `client/public/fonts/*.ttf` | جديد (ملفان) | الخط محلياً (SIL OFL) |
| `client/public/privacy.html` | جديد | سياسة الخصوصية (تُنشر مع Pages) |
| `scripts/make-android-icons.cjs` | جديد | أيقونات/بداية/أصول المتجر بهوية التطبيق |
| `.gitignore` | إضافة قواعد Android | منع رفع المفتاح والبناء |
| `android/gradle.properties` | `android.overridePathCheck=true` | مسار المشروع يحوي حروفاً عربية |
| `android/app/build.gradle` | قراءة `keystore.properties` وتوقيع Release | رفع AAB موقّع إلى Play |

`pnpm check` (tsc) يمرّ بنجاح بعد التعديلات.

## 5) ما يجب أن تعرفه

1. **المرشد/الحساب غير موجودين**: التطبيق لا يحتاج تسجيل دخول إطلاقاً → نموذج أمان البيانات = «لا تُجمع بيانات»، وهذا يسرّع المراجعة.
2. **اسم الحزمة ثابت**: `com.mohammedusa162.oilgasportal` — لا يُغيَّر بعد النشر.
3. **مفتاح التوقيع**: نفس مفتاح تطبيق «متتبع البحث» (مفتاح رفع واحد لكل حساب مطوّر). المفتاح مكرّر في `android/keystore/` هنا، ومُستبعد من Git.
4. **صفحة الخصوصية**: تحتاج دفع التعديلات إلى GitHub حتى تُنشر على Pages ثم تصبح الرابط عاماً.
5. **عدم التوافق المحتمل مع النسخة القديمة**: `vite build` المحلي بمسار `/`، بينما النشر على Pages يستخدم `/oil-gas-student-portal/` — لا تغيّر `BASE_PATH` في CI إلا إن غيّرت مسار الفهرس داخل التطبيق.
